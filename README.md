# News Aggregator v3

Poland/Podlasie-focused RSS news aggregator.

## First launch

Double-click `start.bat`.

It installs dependencies on first run, starts the server, and opens `http://localhost:3000`.

## Later launches

Double-click `start.bat` again. Dependencies are already installed, so it only starts the server and opens the site.

## Structure

- `server.js` — RSS aggregation backend
- `public/index.html` — page structure
- `public/style.css` — design
- `public/script.js` — carousel/filter logic
- `start.bat` — one-click Windows launcher
